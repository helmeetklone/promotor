1. Upload file sumber

Format .xlsx, .xlsb, .xls, .json, atau .ndjson (file gede? convert dulu di xlsx-to-json.html). Employee ID otomatis distandarkan sebagai kunci join.
DOP, File_HR, Absensi, Timestamp, OM/Outlet Master — WAJIB diisi semua. Slot OM/Outlet Master diisi dari 1 file (biasanya export "Visit Activity Frontliner") yang sekalian punya kode/nama toko DAN koordinat GPS-nya — nggak perlu file terpisah lagi.
GAR & NCA — opsional. Slot GAR = file rekap per-promotor yang flat, 1 baris per NIK, TANPA breakdown per brand (nama file biasanya data_GAR_by_Promotor_<bulan>.xlsx). Slot NCA = file yang breakdown per brand XL/AXIS/SMART + per bulan (nama file biasanya NCA_Promotor_<bulan>.xlsx). Kalau salah taruh nggak apa-apa, sistem tetap coba baca ID-nya (NIK), tapi lebih baik sesuai biar kolom hasil merge-nya rapi.
